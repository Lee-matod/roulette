# Roulette

A simple casino-style roulette model written in Python.

## Installing

Execute the following script depending on the operating system you are currently using.  
[Python 3.12](https://www.python.org/downloads/release/python-3120/) or newer is required to be installed in your system beforehand.

```sh
# Linux/macOS
python3 -m pip install git+https://github.com/Lee-matod/roulette
# Windows
py -3 -m pip install git+https://github.com/Lee-matod/roulette
```

## Usage

This project includes both an API and a command-line interface (CLI) tool.

### API library

Each class and method is carefully documented. Read the documentation for each component for usage instructions.
Public classes can be located in [`roulette/roulette.py`](https://github.com/Lee-matod/roulette/blob/main/roulette/roulette.py).

### Command line

To start the CLI tool, run the following depending on the operating system you are currently using.  
Please ensure that you already have Roulette installed in your system.

```sh
# Linux/macOS
python3 -m roulette
# Windows
py -3 -m roulette
```

You will be greeted with a welcome screen followed by a list of available commands.  
Command arguments are requested after a command is executed and are not expected to be given within the same execution line.
